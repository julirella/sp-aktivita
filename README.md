### Instalace:
* Jestli používáš virtuální prostředí tak zapnout, třeba venv:
    * `python3 -m venv env`
    * `source ./env/bin/activate`
* Stáhnout matplotlib: `pip install matplotlib`

### Jak používat
* Spustit: `python3 aktivita.py`
* Objeví se prompt, jsou dvě možnosti:
    1. Zkusit, jestli jsou 2 postavy pár: `<postava1>, <postava2>`
    2. Zobrazit obrázek postavy: `<postava>, img`
    * můžeš vždycky celý jméno nebo jen křestní (první slovo ze jména - třeba `lionel` místo `lionel messi`)
    * postavy dávat bez diakritiky, velký písmena jsou jedno
    * vždycky oddělovat čárkou
    * !HOTFIX: obrázek postavy Diego se musí zobrazit jako `diego2, img`
